# 可选依赖：只处理 YouTube 时才需要。
#
#     pip install -r requirements-youtube.txt
#
# 一个包，1MB。不装它，B站 的所有功能照常工作 —— src/youtube_client.py 在
# import 失败时会抛出带明确指引的 YouTubeUnreachable，不会让整个项目起不来。
#
# 为什么只要这一个、而且必须装：
#   裸 requests 的 TLS 指纹（JA3）会被 YouTube 一眼识破，握手直接被掐断，
#   报 SSL: UNEXPECTED_EOF_WHILE_READING（实测连试 10 次全败）。
#   curl_cffi 能伪装成真实 Chrome 的指纹，装了立刻通。
#
# 曾经依赖过 yt-dlp（19.8MB），后来自己实现了 InnerTube player API 调用
# + 分片并发下载，功能等价，依赖从 20.8MB 降到 1MB。详见 SKILL.md「YouTube」节。
#
# 许可证：curl_cffi 是 MIT，不污染本项目的 MIT。
